## About

Rubber Ducks Syndicate is a collection of projects focused on helping developers work more effectively with modern AI.

Our work includes:

- 🤖 AI skills and reusable workflows
- 🧠 Obsidian knowledge management
- 📚 LLM documentation and wikis
- 🔧 Developer productivity tools
- 📝 Prompt engineering and best practices

The goal is to create practical, reusable resources that improve both human and AI-assisted development.

## Philosophy

> Good documentation scales people.  
> Great documentation scales AI.

We believe that high-quality knowledge management is becoming a core engineering skill in the age of Large Language Models.
